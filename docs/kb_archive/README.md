# Knowledge-base archive

Project-knowledge documents moved here, unchanged, when the project's
knowledge base (cap 2,000,000 bytes) ran short of space. The rule (decision
D-103, 2026-10-21): when the free space falls under 20 KB, the superseded
handoffs and plans -- those a later handoff names as replaced -- are
committed here under their original path and deleted from the knowledge
base; nothing the user uploaded, nothing current, never the decision log.
Each move is listed in the reply that makes it and in the table below.

A document here is history. The current state of any topic is in the
knowledge base: the decision log `claude/SBI_decisions_and_ideas_log.md`,
the latest handoff and plan, `HPC_PATHS.md` and its addenda,
`EXTRACTOR_USAGE.md`.
