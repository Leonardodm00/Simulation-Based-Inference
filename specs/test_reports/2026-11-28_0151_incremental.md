## Problems in the spec

- **S1 (the unit of x, block 46).** D-180 corrected sec. 2.7, block 44 and block 46's label clause. But block 46's Public API ("below, the window's IFR x [Hz per electrode]") and the wave-C contract ("`x` is the subregion's window, (W,) [Hz per electrode]") still give the old unit.
- **S2 (the last bin).** Sec. 2.7 now states K = int(T_rec / Delta t) and float64 edges k Delta t, following the imported function. That function bins with `numpy.histogram`, which closes its last bin. A spike exactly at K Delta t, in a recording longer than K bins, is counted in bin K - 1 rather than dropped (O44.12, test `-k last_edge`). The general clause ("the imported function governs") covers this, but D-180 lists only the other two differences.
- **S3 (Notation).** The Notation row of x still reads "Hz (IFR)" with the 2026-11-12 note "the extractor's banks not checked here". D-180 has since checked them: spikes per bin per electrode.
- **S4.** Block 41's fix round compares `gaussian_window` and `electrodes_per_subset` "where the sidecar holds them". It does not say that no existing bank writer puts them there (F1), so the clause reads as a protection that does not exist in practice.
